# Nominatim Roermond Kaart

Dit is een schoolopdracht in PHP en Leaflet. De code haalt gegevens op via de Nominatim API, haalt de coördinaten van Roermond op en laat ze zien op een kaart met een prikker (marker).

## Hoe start je het op?
1. Zet het bestand `index.php` in je `htdocs` map van XAMPP.
2. Zet XAMPP (Apache) aan.
3. Open je browser en ga naar:
   ```text
   http://localhost/jouw-mapnaam/index.php
